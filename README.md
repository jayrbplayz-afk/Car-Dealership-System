# 🚗 DGV AUTO DEALS

## 📌 Project Overview

DGV AUTO DEALS is a Java-based car dealership management system developed using Java Swing in NetBeans. The system is designed to help manage car inventory, customer transactions, and dealership operations through a graphical user interface.

It allows users to browse available vehicles, search and sort car listings, manage car sales, and generate transaction receipts.

## ✨ Features

- **User Login and Registration** – Allows users to access the system through their accounts.
- **Car Inventory Management** – Displays available new and used vehicles.
- **Search and Sort** – Helps users find cars based on their details and organize listings.
- **Sell a Car** – Allows users to add used cars to the inventory.
- **Car Transactions** – Handles vehicle purchases and transaction details.
- **Transaction Receipt** – Generates and displays purchase receipts.
- **Transaction History** – Allows users to view previous transactions.
- **User Roles** – Supports role-based access within the system.

## 🛠️ Technologies Used

- Java
- Java Swing
- NetBeans IDE
- Object-Oriented Programming (OOP)

## ▶️ How to Run

1. Clone or download this repository.
2. Open NetBeans IDE.
3. Open the DGV AUTO DEALS project.
4. Make sure the required Java files and image assets are included.
5. Run the `MainDriverClass` to start the application.
